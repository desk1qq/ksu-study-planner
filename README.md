# KSU Study Planner

## Возможности

- равномерное распределение задач до даты экзамена;
- обычный текст, нумерованные и маркированные списки;
- автоматическое продолжение `1.`, `2.`, `3.` или маркера `-` при нажатии Enter;
- автоматическое сохранение изменений заметки;
- закреплённые заметки и отдельная группа «Другие»;
- поиск, архив, корзина и восстановление в план подготовки;
- цвета, фоновые узоры и форматирование карточек;
- локальные напоминания на завтра, следующую неделю или выбранное время;
- светлая и тёмная темы;
- адаптивный интерфейс и управление с клавиатуры.

## Запуск

Проект не требует установки пакетов и сборки. Нужен современный браузер.

```powershell
git clone https://github.com/desk1qq/ksu-study-planner.git
cd ksu-study-planner
Start-Process .\keep.html
```

Или скачайте репозиторий и откройте [`keep.html`](keep.html) двойным щелчком.

## Как пользоваться

1. Наведите курсор или нажмите на карточку «К чему готовимся?», чтобы раскрыть форму.
2. Введите название экзамена и будущую дату.
3. Добавьте текст заметки. Для списка начните строку с `1.` или `-`.
4. Нажмите «Составить план».
5. Откройте карточку, чтобы изменить текст, оформление или напоминание.

Корректные изменения в открытой заметке сохраняются автоматически. Отдельная кнопка сохранения не требуется.

## Ввод списков

| Ввод | Результат |
|---|---|
| `Повторить формулы` | Обычный текст без нумерации |
| `1. Повторить формулы` + Enter | Следующая строка начинается с `2.` |
| `- Повторить формулы` + Enter | Следующая строка начинается с `-` |

Тип отображения сохраняется вместе с заметкой.

## Хранение данных

Все планы, оформление и напоминания сохраняются в `localStorage` текущего браузера под ключом `exam-planner-v1`. Данные не отправляются в сеть.

> Очистка данных браузера удалит сохранённые заметки. Для страниц `file://` рекомендуется не менять путь к файлу и использовать тот же браузер.

## Алгоритм распределения

Для `N` задач и `D` доступных календарных дней каждый день получает `Math.floor(N / D)` задач. Первые `N % D` дней получают ещё по одной задаче. Порядок сохраняется, а дни без задач не создаются.

Пример: **5 задач на 3 дня → 2, 2, 1**.

## Ручная проверка

- создать заметку с обычным текстом и убедиться, что номера не появились;
- создать списки с `1.` и `-`, проверить автоматическое продолжение;
- открыть заметку, изменить текст и перезагрузить страницу;
- переместить архивную заметку в корзину и восстановить её в основной план;
- проверить напоминание, обе темы и анимацию бокового меню.

## Ограничения

- синхронизации между устройствами нет;
- напоминания отображаются только при открытой странице;
- задачи считаются одинаковыми по трудоёмкости;
- очистка `localStorage` удаляет данные.

## Планы развития

- отметка выполненных задач и прогресс подготовки;
- перенос невыполненных задач на следующие дни;
- экспорт и импорт резервной копии.
